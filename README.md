# Плашка ЭП в PDF — подписание ГОСТ на Windows

Программа для установки видимого штампа электронной подписи (ЭП, ЭЦП) в PDF-документ. Приложение показывает страницу PDF, позволяет выбрать место плашки мышью и подписывает копию документа ключом ГОСТ через КриптоПро CSP.

## Возможности

- Предпросмотр PDF и выбор страницы.
- Установка плашки кликом и перетаскивание рамки.
- Имя владельца сертификата, дата и время подписи и серийный номер на плашке.
- Встроенная электронная подпись CMS и сохранение подписанного PDF отдельным файлом.

## Как подписать PDF

1. Распакуйте сборку для Windows x64 и запустите `PdfSigner.exe`.
2. Выберите PDF, личный сертификат ГОСТ и страницу.
3. Щёлкните в нужном месте предпросмотра и при необходимости перетащите рамку.
4. Нажмите **Подписать и сохранить…**. При запросе PIN введите его в окне КриптоПро CSP.
5. Откройте подписанный PDF в Acrobat Reader и проверьте подпись на панели **Подписи** с модулем КриптоПро PDF.

## Требования

Windows x64, .NET Framework 4.6.1 или новее, КриптоПро CSP и действующий сертификат ГОСТ в хранилище «Личное». Приложение запускается отдельно от Acrobat. В предпросмотре могут отсутствовать интерактивные поля форм и ранее добавленные штампы.

Размещение плашки и целостность подписанной ревизии проверены с тестовым сертификатом RSA. Подписание на конкретном носителе ГОСТ следует проверить на пробном PDF.
